# Quality Gates

> 交付前逐项打勾；任何一项“不确定”都算未通过。

---

## 1. 内容与来源

- [ ] 每个关键数字能指回论文表图/代码行/结果文件
- [ ] 论文、代码、用户工作三种来源有标签
- [ ] 论文与代码冲突已写成 callout，没有静默选一个
- [ ] 公式符号表完整
- [ ] 每个核心概念至少一个常见误区
- [ ] 负结果/失败/边界保留
- [ ] 没有“显然/众所周知”这类跳过解释的词
- [ ] 没有编造的实验、数字、时间线

## 2. 教学完整性

- [ ] `00_教学规格.md` 有学习者、目标、先修、概念 DAG
- [ ] 目标 ↔ 文档 ↔ 例子 ↔ 练习 ↔ 评估对齐
- [ ] 每篇文档只讲一个核心概念
- [ ] 每篇有“一句话”和“如果你只记一件事”
- [ ] 每篇 3–5 道自测题，答案在 `<details>` 里
- [ ] deep 模式总计 60–100 题
- [ ] 有最终 teach-back 清单
- [ ] 先修顺序无环、无跳跃

## 3. 文档结构

- [ ] 每篇只有一个 H1
- [ ] 标题是判断句，不是“方法/实验”这种空标题
- [ ] 每篇有“下一步”链接
- [ ] 代码块有语言标注
- [ ] 公式统一 `$...$` / `$$...$$`
- [ ] 没有 `\(...\)` / `\[...\]`
- [ ] 代码围栏闭合

## 4. 图与动画

- [ ] 正式图用 TikZ/drawio
- [ ] 每张图有 `.tex`/`.drawio` 源、PDF、PNG
- [ ] 每张图有中文图注 + “看什么”
- [ ] 所有图已插入至少一篇文档
- [ ] 图片可点击打开原图
- [ ] 图内无重叠/出框/被裁
- [ ] HTML 动画单文件、离线可用
- [ ] HTML 动画有播放/暂停/重置
- [ ] HTML 动画通过 `node --check`
- [ ] 动画截图版面正常

## 5. demo

- [ ] 每个 demo 有 README 命令
- [ ] 每个 demo 实际跑过
- [ ] 输出与 README 写的一致
- [ ] 固定随机种子
- [ ] CPU 可跑
- [ ] 结果图已保存
- [ ] 没有隐式依赖外部大数据

## 6. 导航与链接

- [ ] README 有“全部文档（可点击）”总表
- [ ] 每篇顶部有导航
- [ ] 每篇底部有上一节/下一节/返回目录
- [ ] 正文路径都是链接，不是裸路径
- [ ] 所有相对链接存在
- [ ] 所有图片路径存在
- [ ] 没有 `D:\...` 绝对路径
- [ ] 上一节/下一节顺序与学习路线一致

## 7. 交付

- [ ] README 有文件地图、学习路线、验证命令
- [ ] 有最终验收报告
- [ ] `outputs/` 已 gitignore
- [ ] 没有 >20 MB 文件进入 Git
- [ ] 没有密钥/token/密码
- [ ] 只提交教学包文件
- [ ] 没有 `git add -A` 造成无关改动

---

## 8. 自动检查

```bash
python scripts/check_pack.py --root <pack> --require-nav --require-readme-index
python scripts/compile_tikz.py --dir <pack>/动画与图/TikZ --dpi 220
```

`check_pack.py` 应报告：

```text
docs: N
broken links: 0
broken images: 0
missing nav: 0
formula delimiter issues: 0
HTML script issues: 0
```

`compile_tikz.py` 应报告：

```text
compiled: N/N
exported: N/N
```

任何非零退出码都必须修到通过，或在最终报告中明确解释为什么不能修。
